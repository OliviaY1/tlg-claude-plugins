# tlg-prealert 安装说明

## 管理员（air@，只做一次）

两个 API 都用 **air@transleadgroup.com** 登录部署。

### Attachment API
1. script.google.com > 新建项目，粘贴 `gmail-attachments-api.gs`。Project Settings 勾选 "Show appsscript.json"，粘贴 `gmail-attachments-api.appsscript.json`。Save。
2. 函数菜单选 `setup` > Run > 允许权限。
3. Deploy > New deployment > Web app，Execute as **Me**，Who has access **Anyone** > Deploy。
4. 复制以 `/exec` 结尾的链接，填进 `SETTINGS.webAppUrl`，Save，再 Run 一次 `setup`。
5. key 文件 `gmail_attachments_api_key (do not share)` 会出现在 Drive 的 `assests_for_googlesheet_automation` 文件夹里。

### Sheet API
同上，用 `sheet-api.gs` 和 `sheet-api.appsscript.json`。key 文件是 `sheet_api_key (do not share)`。
- 允许的表格在 `SETTINGS.allowedSheets`。air@ 必须是这些表格的编辑者。

### 改代码以后
Deploy > Manage deployments > 编辑（铅笔）> Version 选 **New version** > Deploy。链接和 key 不变。

### 共享
把这两样共享给使用插件的同事（Viewer 即可）：
- `assests_for_googlesheet_automation` 文件夹（含两个 key 文件）
- `email_attachments_for_claude` 文件夹

## 同事（每人一次）

1. **连接器**：Settings > Connectors，连接 Gmail（登录 **air@**）和 Google Drive（自己的公司账号）。
2. **网络**：Settings > Capabilities，打开 Code execution 和 Allow network egress，在 Additional allowed domains 加上 `script.google.com` 和 `script.googleusercontent.com`。Team 方案由 Owner 设置。
3. **安装插件**：Customize > Plugins > Add > Add marketplace，填 `OliviaY1/tlg-claude-plugins`（需要连接 GitHub 并有仓库权限），安装 `tlg-prealert`。或者 Add > Upload plugin，上传 `plugins/tlg-prealert` 打包的 .zip。

## 怎么用

| 说法 | 做什么 |
|---|---|
| 只查预报邮件 / check prealert emails only | 查最近 3 天的预报，对照表格，标出需要人工处理的。不改任何东西。 |
| 只查最近 7 天的预报邮件 | 同上，查 7 天 |
| 把预报录到 2026. JUN 大贸 空运 | 先给清单，确认后存附件、写入表格 |
| 一次性把预报录到 2026. JUN 大贸 空运 | 不停下确认，直接跑完 |

插件不会删除任何东西，也不会修改表格里已有的行。

## 改名字
key 文件夹或 key 文件改名后，只改 `skills/tlg-prealert/config.json`。
